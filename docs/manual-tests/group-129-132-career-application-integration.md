# Groups 129-132 manual verification

Use Ordinary mode for empty-state and persistence checks. Use Portfolio Demo
only for synthetic screenshot evidence.

1. Open Career > Cover Letters & Application Packs in Ordinary mode and verify
   that no fictional opportunity, fact, letter or application appears.
2. Add a manual opportunity, restart Desktop and confirm it remains.
3. Create and save a CV in CV Studio, then add a sourced career fact.
4. Create an opportunity-linked cover-letter draft and confirm generated
   sections are visibly awaiting review.
5. Accept one generated section, reject another and verify export remains
   blocked until the rejected section is replaced with user-authored text.
6. Enable contact-detail inclusion without confirmation and verify export is
   blocked; confirm the choice and verify review passes.
7. Export PDF and DOCX derivatives, open both and verify the opportunity,
   employer and complete reviewed content are present.
8. Approve application preparation and verify no submission or external
   communication occurs.
9. Assemble and approve an application pack, then edit the cover letter and
   verify the pack becomes stale and not ready.
10. Open Full Mobile in Ordinary mode and verify empty state/manual opportunity
    capture; in Portfolio Demo verify synthetic labelling, cover-letter source
    states, pack status and explicit PDF/DOCX share actions.
11. Restart both products and verify persisted ordinary records recover.
12. Confirm invalid or corrupt storage is preserved and the last valid backup
    is loaded without overwriting the unreadable original.
