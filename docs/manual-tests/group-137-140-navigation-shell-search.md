# Groups 137-140 manual test - Navigation and Shell Search

1. Launch LifeOS Desktop and press Ctrl+K.
2. Confirm an empty query browses indexed shell destinations and explicitly
   states that no personal record content is indexed.
3. Type `local backup`; confirm Local Data & Recovery is the selected result
   with its type, match reason and description visible.
4. Press Enter; confirm Settings opens the Local Data & Recovery module.
5. Reopen search and type `theme light`; confirm the preference result is
   identified before it is run. Do not change the theme during evidence capture.
6. Type `definitely unavailable`; confirm zero results and the message that
   nothing will run.
7. Verify Up/Down changes selection, Enter executes only the selected result,
   double-click executes a listed result, and Escape closes the palette.

Do not claim full-text record search, provider search, external search or AI
retrieval. This checkpoint indexes static shell metadata only.
