# Groups 145-148 manual test - Projects and Delivery

1. Launch LifeOS Desktop in Ordinary mode and open Projects > Projects.
2. Confirm the summary starts from real local records and an unused profile
   shows an explicit zero-record empty state.
3. Choose Create project with required fields empty; confirm field errors and
   the actionable problem region appear and no local file is created.
4. Enter an invalid due date; confirm `yyyy-mm-dd` guidance appears.
5. In an approved disposable or isolated demo profile, create a project with a
   next action, due date and proof reference; restart and confirm persistence.
6. Mark the project completed, archive it, then restore it; confirm the record
   identity and content remain intact.
7. Open Local Data & Recovery and confirm Projects is a registered versioned
   store with backup and Trash health.
8. Confirm there is no permanent-delete, provider write, calendar event,
   client message or evidence upload control.

Do not create fictional validation records in the user's ordinary data store.
