# LifeOS v28.0.0-alpha.11 - Groups 161-164

## Household and Grocery Planning

This checkpoint replaces the ordinary proof-only boundary with a genuine local
household grocery workspace backed by validation and recoverable persistence.

### Implemented

- honest ordinary-mode empty state with no seeded lists or essentials
- bounded local grocery item capture with required quantity and unit
- explicit category, priority, required-item, brand and notes fields
- optional recurring cadence and ISO next-due date
- explicit list lifecycle and reversible shopping-item decisions
- duplicate-name review candidates without automatic merge
- atomic, versioned persistence with recoverable Trash
- eighth operational store registration in Local Data & Recovery

### Safety boundary

LifeOS does not automatically order, pay, trust prices, choose substitutions,
merge duplicates, mutate grocery lists from suggestions or write to an external
cart.
