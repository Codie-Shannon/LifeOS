# LifeOS v28.0.0-alpha.16 - Groups 181-184

## Relationships and Contact Context

Groups 181-184 replace the legacy Relationship Radar surface with a genuine
ordinary-mode workspace for local, deliberate relationship memory.

### Included

- validated name, role/context, ISO contact dates, linked work, next action and notes
- explicit waiting-on-them, waiting-on-me, do-not-chase, park, close and reopen actions
- visible due-follow-up and boundary summaries without automatic chasing
- empty ordinary mode and isolated fictional portfolio-demo profiles
- versioned atomic persistence plus recoverable Trash registration
- actionable validation and storage problem states

### Safety boundary

This release does not import contacts, send messages, create reminders, chase a
person, control provider accounts or infer consent. Every authoritative change
requires an explicit local action.
