# LifeOS v28.0.0-alpha.17 - Groups 185-188

## Accounts and Local-First Sync Foundation

Groups 185-188 add a real Settings workspace for one recoverable device-local
profile and an honest data-movement posture.

### Included

- validated local display name and device label
- explicit local-only or manual-transfer posture
- explicit local change counter, pause/resume and manual-transfer checkpoint
- one versioned atomic local-account-sync profile with recoverable Trash
- empty ordinary mode and isolated fictional portfolio demo
- actionable validation and storage problem states

### Configuration boundary

This release does not collect credentials, authenticate a user, choose an
endpoint, upload records, exchange remote conflicts or run background sync.
Provider and background-sync flags are rejected by normalization.
