# LifeOS v28.0.0-alpha.18 - Groups 189-192

## Device Transfer and Conflict Review

Groups 189-192 add a Settings workspace for fingerprint-only device-transfer
manifests and review-first conflict decisions.

### Included

- validated source device, destination device and record key
- strict 64-character SHA-256 fingerprint validation
- deterministic duplicate or conflict classification
- explicit keep-local, keep-incoming-candidate, keep-both and reject decisions
- versioned atomic device-transfer-review persistence and recoverable Trash
- empty ordinary mode and isolated fictional portfolio demo

### Safety boundary

This release stores manifest metadata and decisions only. It does not copy,
decrypt, upload, merge or replace any payload or authoritative record.
