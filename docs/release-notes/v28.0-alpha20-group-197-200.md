# LifeOS v28.0.0-alpha.20 - Groups 197-200

## Connection Testing and Health Diagnostics

Groups 197-200 add a Settings workspace for credentialed-test plans and
explicit health observations without running connections in the
configuration-free product.

### Included

- validated capability, owner and environment
- configuration-reference, authentication, provider-read and provider-write check kinds
- uppercase environment-variable-style secret-reference names
- explicit passed, degraded, failed and blocked manual observations
- versioned atomic connection-health persistence and recoverable Trash
- empty ordinary mode and isolated fictional portfolio demo

### Safety boundary

This release stores diagnostic metadata and manual observations only. It does
not open a network connection, read a secret value, authenticate, select an
endpoint or call a provider.
