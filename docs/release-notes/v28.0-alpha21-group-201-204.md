# LifeOS v28.0.0-alpha.21 - Groups 201-204

## Provider Adapter Registry and Capability Matrix

Groups 201-204 add a Settings workspace for adapter declarations and bounded
capability visibility without loading provider implementations.

### Included

- validated adapter name, provider family, owner and environment
- calendar-read, email-read, file-read, draft-proposal and future-write declarations
- uppercase environment-variable-style credential-reference names
- explicit planned, available-for-test, blocked and retired states
- versioned atomic provider-adapter persistence and recoverable Trash
- empty ordinary mode and isolated fictional portfolio demo

### Safety boundary

This release stores adapter metadata only. It does not load a provider SDK,
resolve a credential, select an endpoint, authenticate or activate provider
writes. The provider-write activation rule always returns false.
