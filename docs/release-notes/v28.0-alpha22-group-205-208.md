# LifeOS v28.0.0-alpha.22 - Groups 205-208

## Provider Consent and Permission Profiles

Groups 205-208 add a Settings workspace for explicit, purpose-bound provider
consent and close the approved configuration-free development lane.

### Included

- validated profile, provider family, owner, environment and purpose
- bounded capability requests and optional deterministic expiry
- explicit proposed, approved, paused, revoked and expired states
- versioned atomic provider-consent persistence and recoverable Trash
- empty ordinary mode and isolated fictional portfolio demo

### Safety boundary

This release stores consent metadata only. Approval does not enable OAuth,
resolve credentials, select endpoints, authenticate or call providers.
