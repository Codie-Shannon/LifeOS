## Permanent boundaries

- LifeOS does not submit applications or contact employers.
- Generated wording is never promoted to accepted text silently.
- Missing, stale or unsupported source claims block export.
- A pack is not ready until its current CV and cover-letter versions pass
  explicit review.
- Portfolio proof remains isolated behind Portfolio Demo mode.
