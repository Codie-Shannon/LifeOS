# LifeOS v28.0.0-alpha.4 - Groups 133-136

Groups 133-136 establish the first configuration-free Local Data and Recovery
spine.

## Shipped in Pack 1

- A shared versioned JSON envelope for operational local stores.
- Atomic write-through replacement with validated backup preservation.
- Honest missing-file state that does not create or seed data.
- Legacy raw-payload and older-schema migration with source preservation.
- Corrupt-primary preservation and validated backup recovery.
- Fail-closed handling for newer schemas and mismatched store identities.
- Recoverable 30-day Trash for Agenda, Follow-ups, Work Pipeline and Work
  Sessions.
- Guarded restore that refuses to overwrite current data or follow paths
  outside a store's registered Trash directory.
- A Desktop Settings surface for registered-store health and recovery.

## Deliberate boundaries

- This checkpoint migrates four operational stores, not every LifeOS store.
- No permanent-delete action or automatic Trash purge is enabled yet.
- No encrypted whole-product backup, cloud sync or provider configuration is
  claimed.
- Portfolio Demo remains an explicit mode; ordinary missing data stays empty.
