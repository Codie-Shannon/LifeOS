# LifeOS v28.0.0-alpha.5 - Groups 137-140

Groups 137-140 add ranked, configuration-free navigation and shell search.

## Shipped in Pack 1

- A deterministic search and ranking service in Shared Core.
- A live Desktop result list for all nine workspaces, allowlisted module routes
  and safe appearance commands.
- Exact title, command, title-prefix, keyword and description ranking.
- Stable ordering, duplicate-ID suppression and an eight-result ceiling.
- Up/Down selection, Enter execution and double-click execution.
- Visible target type, match reason and description before execution.
- Explicit no-result feedback that confirms nothing ran.

## Boundaries

- Personal record content is not indexed.
- Provider content and external search are not queried.
- Only listed safe display commands can mutate preferences.
- A result must be selected before any navigation or preference action runs.
