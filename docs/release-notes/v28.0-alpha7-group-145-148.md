# LifeOS v28.0.0-alpha.7 - Groups 145-148

Groups 145-148 replace the planned Projects placeholder with a real, local,
ordinary-mode delivery workspace.

## Shipped in Pack 1

- Honest empty state without portfolio-proof seeding.
- Validated project name, next action, date and bounded text inputs.
- Explicit backlog, active, waiting, blocked, completed and archived states.
- Optional due date, summary, notes and proof reference.
- Versioned atomic persistence with backup health and recoverable Trash.
- Reversible archive/restore without permanent deletion.
- Safe actionable problem states for local write failures.
- Accessible automation identities for fields, errors, actions and the live
  problem region.

## Boundaries

- No provider, client, calendar, accounting or messaging action is created.
- Proof references are pointers only; evidence is not copied or uploaded.
- Ordinary mode does not infer projects from existing records.
- Project editing beyond status transitions remains later product work.
