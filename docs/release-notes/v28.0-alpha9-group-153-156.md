# LifeOS v28.0.0-alpha.9 - Groups 153-156

## Money Pressure and Safe to Spend

This checkpoint replaces seeded ordinary defaults and direct JSON writes with
an honest local money snapshot backed by the shared recovery contract.

### Implemented

- ordinary-mode zero state with no invented balance, income, bills or buffers
- validated local amounts with explicit field errors and recovery guidance
- negative current balance support without negative obligations or buffers
- deterministic safe-to-spend with pending income excluded by default
- visible reasons and pressure state derived from current-week estimates
- atomic, backup-aware versioned persistence with legacy preservation and Trash
- sixth operational store registration in Local Data & Recovery

### Safety boundary

Every number is user supplied. LifeOS does not claim a live bank balance,
verify a payment, initiate money movement, write to an accounting provider,
reconcile automatically or provide financial advice.
